# Stem Reference Studio (Prototype)

DAWライクな見た目で、stem音源管理とリファレンス研究を行うWebプロトタイプです。

## 実装済み（MVPプロトタイプ）
- 曲ライブラリ（最大1000曲・検索・ページング）
- 曲詳細編集
  - マルチトラックstem管理（名前・メモ・音源添付）
  - 波形表示（添付音源から簡易抽出）
  - セクションマーカー管理
  - BPM/曲メモ管理
  - 小節単位コード入力
- 横断検索（キーワード/コード/BPMレンジ）
- 統計（登録曲数、平均BPM、頻出コード）

## 使い方
```bash
python3 -m http.server 4173
```

ブラウザで `http://localhost:4173` を開いてください。

> データは `localStorage` に保存されます（音源ファイル本体は永続化しません）。
