# Stem Reference Studio（設計ドラフト）

Web上で動く **stem音源管理 + リファレンス研究ソフト** の初期設計です。

## 目的
- DAWライクなUIで、曲ごとのstemをマルチトラック管理
- 曲構成（マーカー）、コード進行、BPM、トラックメモを蓄積
- 後から横断検索して、制作時のリファレンス研究に使う

## MVPで実装する要素
- DAW風タイムライン + 波形表示（簡易）
- 曲（最大1000件を想定）の管理
- 1曲ごとのマーカー定義（Intro / Verse / Chorus など）
- トラック単位メモ
- 小節単位コード進行定義
- BPM設定
- 統計・検索（コード、メモ、BPM、セクション）

詳細は `docs/design.md` を参照してください。
